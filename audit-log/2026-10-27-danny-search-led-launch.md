## What changes

Extend existing number reconciliation with denominator-correct search-to-orders maths,
explicit assumptions and an input for the existing offline forecast. Add narrow
Product Hunt exact-link/syndication checks, asset-rights and free-tier caveats, and
ongoing measurement routing. Qualify deterministic KD/backlink/timing and DR-value
claims in the operative metrics guidance. Keep course-index/source history intact.
No new collector, forecast engine, independent workflow or directory candidate is added.

## Not verified

The $1,200 monthly revenue, 1,000+ ranking keywords, 95% traffic share, universal
country multiplier, 2% conversion rate, backlink counts, historical DR, automatic
syndication and fixed ranking times remain source claims. A free tier or longer
engagement does not prove a ranking effect; audience size was not a controlled variable.
Current Product Hunt eligibility, costs, listing `rel`, Figcomponents revenue,
Figma asset licences and a new niche were not live-verified in this source review.
No signup, scrape of private data, external publication, payment, live experiment,
installation, scheduler change, merge or production deployment is authorized here.

## Reproduction

Run `python3 -m unittest discover -s tests -v`, `git diff --check`, and the existing
forecast example in `references/playbooks/research/number-reconciliation.md`.
The source-map test checks all 20 unique status IDs, hashes, decisions and existing
homes. The scenario tests recompute expected orders with exact decimal arithmetic
and exercise the existing forecast CLI. Test passing proves local deterministic
behaviour, not future traffic, ranking or revenue.
