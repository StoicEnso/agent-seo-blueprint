# Keyword Research Tools — Use Available Evidence

**What it is.** A capability and budget decision. Ahrefs is the course's reference interface, not a mandatory subscription or a claim that providers share identical data.

**When to use.** Before collecting keywords, when mapping course panels to an available provider, or when reviewing access and cost constraints.

**Method.**
1. Inventory already-authorised tools and access. Use relevant first-party property evidence, public SERPs, customer evidence and available provider exports before proposing a purchase.
2. Map each task to a suitable source. GSC shows property appearances; Keyword Planner and commercial providers provide estimates with their own definitions, coverage, grouping and limitations. None is ground truth for every job.
3. Retain provider names, capture dates, date windows, country/engine, units and status. Volume, KD, authority and CPC can disagree. Keep disagreement visible; never replace one provider's definition with another's label.
4. Map equivalent panels by purpose, not assumed data parity. Ahrefs, Semrush and Mangools need not return identical values. Do not make a user switch merely to match a course screenshot.
5. If existing evidence cannot answer a load-bearing question, record that gap. Check current destination-owned plan, API entitlement, limits and price before proposing extra access. Purchase, upgrade and paid provider calls need the user's approved scope and budget.
6. AI may expand seeds, classify intent and cluster supplied evidence. It must not invent volume, KD, CPC, trends or prompt demand. A live connector needs a source receipt; a successful helper stub is not a collection receipt.

**Decision criteria / heuristics.** Prefer adequate existing access, comparable evidence and explicit limits over an assumed cheapest plan. Free or first-party sources can answer bounded questions; their limitations must stay visible. A paid subscription is not proof of completeness, accuracy or future profit.

**Example.** A project already has a Semrush export and GSC access. Keep each source's definitions and inspect current SERPs. Ask about added access only for a demonstrated evidence gap, not for interface consistency.

**Pitfalls.** Claiming all tools use interchangeable numbers; assuming a plan's current price or API rights; spending without approval; or calling an AI-generated number provider data.
