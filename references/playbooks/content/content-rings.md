# Content Rings

**What it is.** A small set of separate, owned websites (usually free tools or free-resource sites) that each attract their own audience and backlinks, then link back to your main business — boosting its domain authority and funneling visitors to it. A controlled, white-hat version of a network; overdone, it degenerates into a penalized private blog network (PBN).

**When to use.**
- You want strong backlinks and a launch boost for a new main site, but don't want to host these links on the main site itself.
- You own (or can acquire) a few useful free tools/resources that earn natural links and have their own traffic.
- The satellite sites are older and/or topically distinct from the main site, so links read as natural.

**Method.**
1. Build or acquire a few genuinely useful sites — ideally free tools or free-resource/curation sites that people naturally link to (acquirable cheaply from indie hackers / Product Hunt).
2. Let each site build its own audience and backlinks over time (older, established sites carry more weight).
3. Link from each satellite back to your main business — typically a sidebar or contextual link — to pass authority and send visitors.
4. Use cross-promotion: an unrelated-but-overlapping audience (e.g. a landing-page inspiration site whose visitors might want a LinkedIn headshot) can be funneled to the main product.
5. Keep it SMALL — a handful of strong properties, not dozens.

**Decision criteria / heuristics.**
- Few strong resources beat many weak blogs.
- Topical distance is fine and even useful (the satellites don't need to be about the same thing), as long as audiences plausibly overlap as buyers.
- Hosting these promotional links off the main site (on older, established satellites) is preferable to crowding the main site.

**Example.** A main product (HeadshotPro) is backed by three powerful owned properties — a landing-page inspiration site, a Figma-components site, and a profile-picture site. Each links back (e.g. via sidebar) to the main product or to each other, passing authority and sending overlapping-audience traffic (landing-page visitors who might want a LinkedIn headshot). It's used as an internal promotion engine, not a content farm.

**Pitfalls.**
- Overdoing it: scaling to 20-30+ sites turns this into a PBN. Google detects common ownership (even across different IPs), discounts the links, and may penalize.
- Spinning up many thin blogs with generated content purely to link back — classic black-hat behavior that gets flagged.
